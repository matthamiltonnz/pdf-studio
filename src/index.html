    How it works

    PDF Studio is a self-contained web page. There is no server, no account and no analytics.

    Privacy

    Every file you open is read directly by this browser tab. Merging, splitting, signing and marking up all happen locally using JavaScript. Nothing is uploaded, and the page makes no network requests.

    You can disconnect from the network after the page has loaded and everything will keep working.

    Merge

    Add two or more PDFs, reorder them with the arrows, then choose Merge & download. Page content, sizes, rotations and page-level annotations are preserved. Document outlines/bookmarks and interactive form fields may not carry over.

    Split & organise

    Select pages by clicking their thumbnails. Rotate, move or delete the selection, then save the changes. You can extract just the selected pages, split every N pages, or create one PDF per custom range.

    Splitting into more than one output produces a ZIP file. Pages are copied rather than re-rendered, so the original quality is kept.

    Sign & mark up

    Pick a tool and interact with the page:

    • Highlight, Rectangle and Arrow — drag to draw.
    • Box — drag to cover content visually in any colour. The text underneath is still in the PDF and can be searched or copied; use Redact to remove it permanently.
    • Redact — drag to permanently remove content. Redaction is destructive when the PDF is exported.
    • Draw — freehand ink.
    • Text and Comment — click a page, type, then add.
    • Signature — draw, type or upload a signature, then drag a box on the page.
    • Select — click an annotation to move it; drag the bottom-right handle to resize shapes and signatures. Press Delete to remove it.

    Use the Width menu and the zoom buttons above the document to switch between fit width, fit page and fixed zoom levels. The page area expands to use the available window when a PDF is open.

    On download, annotations are saved as real PDF annotation objects by default (highlight, square, ink, line, free text and stamp). Other PDF readers can list and edit them in their annotation or comment panels. Uncheck Editable annotations to flatten them into the page instead.

    Redact is destructive and different from a box. Every page containing a redaction is rebuilt from a ~144 DPI image on export. In the downloaded PDF, those pages lose their original text (it is no longer selectable or searchable), images, links, form fields, existing annotations and other objects. Document outlines/bookmarks may also be lost. Covered content cannot be recovered from the downloaded copy. Other pages remain untouched where possible.

    Good to know

    • Password-protected PDFs are not supported. Remove the password first, then edit the file.
    • Text annotations use a built-in PDF font that covers Western European characters. Other scripts may be replaced with ?; use an image-based signature for names in other scripts.
    • The Redact tool permanently removes covered content from the downloaded PDF by rasterising the affected pages at roughly 2× page resolution (~144 DPI). On those pages, text is no longer selectable or searchable, and images, links, form fields, existing annotations and other objects are flattened or removed. It is not reversible in that file; keep the original if you may need the underlying text. Links and form fields on redacted pages are flattened, and outlines may be lost.
    • The Box tool is visual only. It draws an opaque cover, but the underlying text and objects remain in the downloaded PDF and can still be selected, searched or extracted. Use Redact when removal is required.
    • Signatures placed here are visual e-signatures. They are not cryptographic digital signatures and do not include a certificate. In editable-annotation mode they are saved as Stamp annotations.
    • Annotations that already exist in an opened PDF are rendered and listed as embedded/read-only. PDF Studio does not import them into its editable overlay; use a PDF reader’s annotation panel to edit them.
    • Very large PDFs or very long pages can take a moment to render. Nothing is lost while the page is working.

    Hosting it in Microsoft 365

    1. Upload pdf-studio.html to a SharePoint document library (for example Site Assets).
    2. Share the file with the people who need it. Because it is a single HTML file with all libraries inlined, no build step or server is required.
    3. For a polished experience, host the file on Azure Static Web Apps (or any static host) and add it to a SharePoint page with the Embed web part, or to a Teams tab.

    Some tenants download HTML files instead of opening them in the browser, depending on library settings. In that case, download the file and double-click it — it works offline from your desktop too.
